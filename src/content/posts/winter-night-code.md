夜里写代码的时候，屏幕是房间里唯一亮着的东西。既然要盯那么久，不如把它好看一点——这个站点的所有配色，都是围绕一句话调的：**黑得下去，也看得清**。

## 为什么是深色

不是因为深色高级，而是因为深色安静。

深色背景会把亮度对比拉大，字只要稍微一亮，就格外清楚。代价是配色稍不注意就会显得脏，所以这里的规则很简单：背景只用低饱和度的蓝黑，强调色只用一个冰蓝，其他都交给留白。

> 好的排版不让人注意到排版，只让人想继续读下去。

## 一段代码

随手写个下雪的小函数，就是这个站点背景的简化版：

```javascript
function snowflakes(count = 120) {
  return Array.from({ length: count }, () => ({
    x: Math.random() * window.innerWidth,
    y: Math.random() * window.innerHeight,
    r: 0.8 + Math.random() * 3.2,
    vy: 10 + Math.random() * 30,
  }));
}
```

行内代码长这样：`requestAnimationFrame`、`prefers-reduced-motion`。

## 一些清单

写这篇文章时想要的东西：

1. 雪花要慢，慢到不用一直看它
2. 星星要少，少到不会显得吵
3. 正文要能一口气读完，中间不需要停下来喘气

顺便列几个不想要的：

- 打开就弹出来的东西
- 一直在动的装饰元素
- 需要三个插件才能正常显示的字体
